# the-buzz
WSBU 88.3 The Buzz - Software Engineering Project

This application is built using Spring Boot

ALL FUNCTIONALITIES:
ALL USERS CAN:
- Play live stream
- Play prerecorded streams
- Add favorites
- remove favorites
- like shows
- like comments
- post comments
- delete comments
- modify account info
- delete account
DJs CAN:
- see DJ system panels
- create DJ profile
- modify DJ profile
- delete DJ profile
- create show listing
- modify show listing
- delete show listing
- upload prerecorded show audio
- delete prerecorded show audio
MODERATORS CAN:
- see ALL system panels
- modify ANY DJ profile
- create ANY DJ profile
- delete ANY DJ profile
- delete ANY comments
- create ANY show listing
- modify ANY show listing
- delete ANY show listing
- upload ANY prerecorded show audio
- delete ANY prerecorded show audio
- modify show schedule visibility
- view account action logs
- create account actions
- modify account actions
- delete account actions
- modify account info
- delete account info
- create permission groups
- modify permission groups
- delete permission groups
- set default permission group
- view server runtime logs
- view system usage statistics
- download system usage statistics
- upload stream audio
- set stream audio to record or not
SYSTEM CAN:
- remove sessions
- add sessions
- invalidate sessions
- modify sessions
